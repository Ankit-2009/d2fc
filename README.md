# D²FC-Based Chaos Control in a Two-Cell FitzHugh–Nagumo Model

## Overview

This project investigates the application of **Delayed Full Feedback Control (D²FC)** to a heterogeneous two-cell FitzHugh–Nagumo cardiac model. The simulation focuses on stabilizing pathological oscillations and suppressing Early Afterdepolarizations (EADs) through delayed feedback control.

The project uses Python-based numerical simulations to study the system's dynamical behavior under control.

## Project Context

This work is a **course-based research project** undertaken for academic credit in the subject *Nonlinear Dynamics and Chaos*.

The project is carried out by four students under the guidance of **Dr. Mary Samuel**.

## Objectives

- Simulate the dynamics of a heterogeneous two-cell FitzHugh–Nagumo cardiac model.
- Implement Delayed Full Feedback Control (D²FC).
- Investigate the stabilization of pathological oscillations.
- Study the suppression of EAD-like activity through delayed feedback control.
